Call the rtk_status tool (rtk plugin) once. Its answer is Markdown: show everything above its **Choices** section as is, not in a code block, with no commentary. Then ask the user which pipelines their tasks should use, with the entries of the **Choices** section as the options: if the AskUserQuestion tool is available, use it with one single-select question, each option's label being the choice's bold title and its description the rest of the line; otherwise show the numbered list and ask them to answer with a number. If the user chooses a reviewed pipeline, call rtk_pipelines with action "add" and source set to that pipeline's name, show its answer as is, and add that it applies from the next new task. If they keep the defaults and the defaults are not in use now, call rtk_pipelines with action "reset" and show its answer. If the choice is already in use, answer in one line that nothing changed. If the rtk_status tool is not available, tell the user in one line that RTK's service on their computer is not reachable from this task and that quitting and reopening Claude Desktop usually fixes it.

# راهنمای فارسی RTK (Rust Token Killer)

این ابزار یک پروکسی CLI با عملکرد بالاست که مصرف توکن مدل‌های هوش مصنوعی (LLM) را ۶۰ تا ۹۰ درصد کاهش می‌دهد.

## چرا از RTK استفاده کنیم؟

هوش مصنوعی گاهی برای درک کدهای شما نیاز به خواندن خروجی‌های طولانی ترمینال دارد. RTK این خروجی‌ها (مثل logها، نتایج تست‌ها یا git status) را هوشمندانه فشرده می‌کند تا فقط بخش‌های ضروری به هوش مصنوعی برسد. این کار باعث می‌شود:

* هزینه‌های API کاهش یابد.
* سرعت پاسخ‌دهی هوش مصنوعی افزایش یابد.
* پنجره کانتکست (Context Window) مدل شما بیهوده پر نشود.

## نصب و راه‌اندازی (مرحله به مرحله)

### ۱. دریافت فایل

برای ویندوز، فایل `rtk-x86_64-pc-windows-msvc.zip` را از بخش [Releases](https://github.com/rtk-ai/rtk/releases) در گیت‌هاب دانلود و استخراج کنید.

### ۲. تنظیم مسیر (PATH)

فایل `rtk.exe` را در یک پوشه ثابت (مثلاً `C:\RTK`) قرار دهید. سپس:

1. منوی استارت را باز کنید و `Environment Variables` را جستجو کنید.
2. روی `Edit the system environment variables` کلیک کرده و دکمه `Environment Variables` را بزنید.
3. در بخش `System variables` گزینه `Path` را انتخاب و `Edit` را بزنید.
4. آدرس پوشه (`C:\RTK`) را با زدن `New` اضافه کنید و همه پنجره‌ها را `OK` کنید.

### ۳. مقداردهی اولیه برای Google Antigravity

در ترمینال خود (CMD یا PowerShell) به پوشه پروژه بروید و دستور زیر را اجرا کنید:

```bash
rtk init --agent antigravity

```

پس از این دستور، فایل قوانین لازم در مسیر `.agents/rules/antigravity-rtk-rules.md` ایجاد می‌شود.

## تست صحت عملکرد

برای اطمینان از نصب صحیح، دستور زیر را در ترمینال بزنید:

```bash
rtk --version

```

و برای مشاهده میزان صرفه‌جویی در توکن‌ها از دستور زیر استفاده کنید:

```bash
rtk gain

```

## دستورات پرکاربرد

* `rtk ls .`: نمایش درختی فایل‌ها با فشرده‌سازی.
* `rtk git status`: نمایش وضعیت گیت بدون جزئیات اضافی.
* `rtk cargo test`: اجرای تست‌ها و نمایش فقط خطاهای مهم.

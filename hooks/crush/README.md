# Charmbracelet Crush Hooks

> Part of [`hooks/`](../README.md) — see also [`src/hooks/`](../../src/hooks/README.md) for installation code

## Specifics

- Skill-based integration (no programmatic hook) — relies on Crush's native skill/Markdown system
- `SKILL.md` contains the instruction to prefix all shell commands with `rtk`, usage examples, and meta commands
- Installed to `.agents/skills/rtk-awareness/SKILL.md` (project-local) by `rtk init --agent crush`

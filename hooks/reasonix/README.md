# Reasonix Hooks

> Part of [`hooks/`](../README.md) — see also [`src/hooks/`](../../src/hooks/README.md) for installation code

## Specifics

- Prompt-level guidance via awareness document — no programmatic hook
- `rtk-awareness.md` is injected into `AGENTS.md` with an `@RTK.md` reference
- Installed to XDG config dir (e.g. `~/.config/reasonix/` on Linux, `~/Library/Application Support/reasonix/` on macOS), by `rtk init --reasonix`
